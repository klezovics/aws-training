# Topics
Here a bunch of services are given which are useful for security, deployments and ops

- Secrets Manager -> stores secrets
- L7 Firewall -> better filtration on HTTP level
- WAF & others -> implements the thingy from above
- Shield -> DDoS protection
- CloudHSM -> some key storage
- Config -> like config maps in K8S
- Macie -> looks for sensitive data (PII) in S3
- Inspector -> vulnerability scanner
- GuardDuty -> threat detection from logs
