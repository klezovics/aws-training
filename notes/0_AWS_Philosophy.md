# AWS

To learn AWS you need to do this:
- There are 7 main service categories: auth, compute, networking, storage, config, glue, ops
- You need to learn the main 30 services spread accross these categories. You learn their domain model and interface
- Then you learn their common combination
- Then you learn the well-architected framework

# Key stuff
## King and Queen
- IAM and VPC are the 2 key objects
- IAM gates every API call, VPC gates every packet
